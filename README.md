Title: CGPA Calcualtor

CGPA Calculator is a simple command-line application developed using C++. The program allows users to enter student information, course details, credit hours, and grades. It calculates the current semester GPA and overall CGPA.
This project was developed to practice C++ programming and object-oriented programming concepts.

Features:
- Enter student name.
- Enter current semester.
- Enter number of courses.
- Add course name, credit hours, and grade.
- Display course details.
- Calculate total credit hours.
- Calculate total grade points.
- Calculate semester GPA.
- Enter previous semester GPAs.
- Calculate overall CGPA.
- Display final result.

How to Run:
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Make sure a C++ compiler is installed.
4. Open the terminal in the project folder.
5. Compile the program using: "g++ CGPA_Calculator.cpp -o CGPA_Calculator"
6. Run the program: "./CGPA_Calculator"
7. Follow the instructions displayed in the terminal.
